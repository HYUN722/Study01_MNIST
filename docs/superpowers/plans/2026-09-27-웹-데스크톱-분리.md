## Global Constraints

- 웹 버전 외부 의존성 **0개**. CDN·npm·번들러·프레임워크 금지. 정적 파일만으로 동작해야 한다.
- 모델 구조는 기존 `MnistCNN` 유지: Conv(1→32,3×3) → ReLU → Conv(32→64,3×3) → ReLU → MaxPool(2×2) → Flatten(9216) → FC(9216→128) → ReLU → FC(128→10).
- 정규화 상수는 평균 `0.1307`, 표준편차 `0.3081` — 두 버전 동일.
- 축소 크기 긴 변 `20px`, 무게중심 목표 `(13.5, 13.5)` — 두 버전 동일.
- 가중치 순서는 `conv1.weight, conv1.bias, conv2.weight, conv2.bias, fc1.weight, fc1.bias, fc2.weight, fc2.bias` 고정. 총 `1,199,882`개 실수 = `4,799,528` 바이트.
- 텐서 배치는 파이토치와 동일: 합성곱 `[출력채널][입력채널][행][열]`, 완전연결 `[출력][입력]`, 특징 맵 `(채널, 높이, 너비)`.
- 코드·주석·변수명·출력 메시지를 전부 한글로 쓴다. 예외는 외부 API 이름과 표준 파일명.
- 모든 새 파일 첫머리에 `작성일: YYYY-MM-DD HH:MM (KST)` 주석을 둔다.
- 사용자가 그린 그림을 서버로 전송하지 않는다.

- [ ] **Step 1: 이동 스크립트 작성**

파이썬 코드가 `Path(__file__).parent` 기준으로 동작하므로 경로 수정 없이 이동만 하면 된다. 덮어쓰기를 막는 것이 핵심이다.

```python
def 옮기기(원본: Path, 목적지_폴더: Path) -> str:
    if not 원본.exists():
        return f"  건너뜀 : {원본.name} (없음)"
    목적지_폴더.mkdir(parents=True, exist_ok=True)
    목적지 = 목적지_폴더 / 원본.name
    if 목적지.exists():
        return f"  건너뜀 : {원본.name} (목적지에 이미 있음)"
    shutil.move(str(원본), str(목적지))
    return f"  옮김   : {원본.name} → {목적지_폴더.name}/"
```
