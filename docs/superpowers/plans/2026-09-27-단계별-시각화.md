# 단계별 시각화(발표 모드) 구현 계획

<!-- 작성일: 2026-09-27 04:45 (KST) -->

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** CNN 이 손글씨를 처리하는 여섯 단계를 발표 자리에서 하나씩 넘겨 보여 주는 정적 웹 화면을 만든다.

**Architecture:** `model.js` 에 중간 결과까지 돌려주는 `추론_단계별()` 을 두고, 기존 `추론()` 은 거기서 확률만 꺼내는 래퍼가 된다. 발표 화면 `steps.html` 은 `model.js`·`preprocess.js` 를 그대로 재사용하는 소비자일 뿐이며, 계산 코드를 스스로 갖지 않는다. 특징 지도는 오프스크린 캔버스에 격자로 한 번에 그려 화면 캔버스로 옮긴다.

**Tech Stack:** 브라우저 표준 API(Canvas 2D, fetch, Float32Array, KeyboardEvent)만. 외부 라이브러리 0개. 테스트는 node(단위)와 playwright(화면).

**Spec:** `docs/superpowers/specs/2026-09-27-단계별-시각화-design.md`

## Global Constraints

- 외부 의존성 **0개**. CDN·npm·번들러·프레임워크 금지. 정적 파일만으로 GitHub Pages 에서 동작해야 한다.
- 추론 계산은 `model.js` **한 벌만** 존재한다. 발표 페이지는 계산을 다시 구현하지 않는다.
- `추론(가중치, 입력)` 의 반환값과 동작은 **바뀌지 않는다** — 길이 10 Float32Array, 입력 길이가 784 가 아니면 예외.
- 특징 지도는 **지도 한 장마다** 자기 최솟값·최댓값으로 0~255 에 편다. 층 전체를 한 기준으로 맞추지 않는다.
- 단계는 정확히 여섯 개: 입력 전처리 / 합성곱1(26×26×32) / 합성곱2(24×24×64) / 최대풀링(12×12×64) / 완전연결1(128) / 출력(10).
- 코드·주석·변수명·출력 메시지를 한글로 쓴다. 예외는 외부 API 이름과 표준 파일명.
- 모든 새 파일 첫머리에 `작성일: YYYY-MM-DD HH:MM (KST)` 주석. 시각은 한국 표준시(UTC+9).
- `index.html` 의 기존 동작과 겉모습은 달라지지 않는다.

## Review Focus

스펙이 요구하지만 태스크 테스트가 직접 건드리지 않아, 발표 당일에 사람을 물 가능성이 높은 것 다섯 가지. 각 줄의 테스트는 담당 태스크에 넣었다.

1. **아무것도 안 그린 채 발표 페이지 진입** — 단계 화면이 빈 캔버스로 깨지지 않고 "숫자를 먼저 그려 주세요"를 보여야 한다. → Task 4
2. **`model.bin` 을 못 읽는 상태** — 발표 페이지에서도 하얀 화면 대신 원인이 떠야 한다. 발표 중 네트워크가 끊기면 실제로 일어난다. → Task 4
3. **ReLU 로 전부 0 이 된 특징 지도** — 최솟값과 최댓값이 같아 정규화에서 0 으로 나누면 `NaN` 이 되고 타일이 깨진다. → Task 2
4. **64장 타일 렌더링 비용** — 단계를 넘길 때마다 다시 그리면 모바일에서 멈춘다. 한 번 계산한 결과를 다시 쓰는지. → Task 2
5. **기존 화면 회귀** — `추론()` 을 래퍼로 바꾸면서 메인 앱이 조용히 깨지는 경우. → Task 1

```javascript
function 지도를_0_255로_펴기(값, 시작, 개수) {
  let 최소 = Infinity, 최대 = -Infinity;
  for (let i = 0; i < 개수; i++) {
    const v = 값[시작 + i];
    if (v < 최소) 최소 = v;
    if (v > 최대) 최대 = v;
  }
  const 폭 = 최대 - 최소;
  const 결과 = new Uint8ClampedArray(개수);
  if (폭 === 0) return 결과;              // 전부 같은 값이면 검정. 0 으로 나누지 않는다.
  for (let i = 0; i < 개수; i++) {
    결과[i] = ((값[시작 + i] - 최소) / 폭) * 255;
  }
  return 결과;
}

function 타일_배치(채널수, 크기, 열수, 여백) {
  const 줄수 = Math.ceil(채널수 / 열수);
  const 위치들 = [];
  for (let i = 0; i < 채널수; i++) {
    위치들.push({
      x: 여백 + (i % 열수) * (크기 + 여백),
      y: 여백 + Math.floor(i / 열수) * (크기 + 여백),
    });
  }
  return { 너비: 열수 * 크기 + (열수 + 1) * 여백, 높이: 줄수 * 크기 + (줄수 + 1) * 여백, 위치들 };
}
```

`특징지도_그리기` 는 오프스크린 `ImageData` 한 장을 만들어 모든 타일을 찍고 마지막에 한 번만 `putImageData` 한다 (Review Focus 4).

```javascript
function 특징지도_그리기(캔버스, 묶음, 열수 = 8, 여백 = 2) {
  const { 값, 채널, 크기 } = 묶음;
  const 배치 = 타일_배치(채널, 크기, 열수, 여백);
  캔버스.width = 배치.너비;
  캔버스.height = 배치.높이;
  const 맥락 = 캔버스.getContext("2d");
  const 이미지 = 맥락.createImageData(배치.너비, 배치.높이);
  const 면 = 크기 * 크기;
  for (let 채 = 0; 채 < 채널; 채++) {
    const 편값 = 지도를_0_255로_펴기(값, 채 * 면, 면);
    const { x: 왼, y: 위 } = 배치.위치들[채];
    for (let 행 = 0; 행 < 크기; 행++) {
      for (let 열 = 0; 열 < 크기; 열++) {
        const 밝기 = 편값[행 * 크기 + 열];
        const 자리 = ((위 + 행) * 배치.너비 + (왼 + 열)) * 4;
        이미지.data[자리] = 이미지.data[자리 + 1] = 이미지.data[자리 + 2] = 밝기;
        이미지.data[자리 + 3] = 255;
      }
    }
  }
  맥락.putImageData(이미지, 0, 0);
}
```

- [ ] **Step 2: 빈 상태를 먼저 처리한다** *(Review Focus 1)*

아무것도 그리지 않은 채로 단계를 넘길 수 있어야 하고, 그때 캔버스가 아니라 안내 문구가 보여야 한다.

```javascript
function 단계_그리기() {
  const 단계 = 단계들[현재단계];
  단계제목.textContent = 단계.제목;
  단계크기.textContent = 단계.크기;
  단계설명.textContent = 단계.설명;
  단계화면.replaceChildren();

  if (!마지막결과) {
    const 안내 = document.createElement("p");
    안내.className = "빈안내";
    안내.textContent = "왼쪽 칸에 숫자를 먼저 그려 주세요.";
    단계화면.appendChild(안내);
    return;
  }
  단계.그리기(마지막결과);
}
```

- [ ] **Step 3: 계산은 한 번만, 전환은 다시 그리기만** *(Review Focus 4)*

손을 뗄 때 `추론_단계별()` 을 한 번 돌려 결과를 보관하고, 단계 전환은 보관한 결과에서 그리기만 한다.

```javascript
function 인식() {
  const 전처리결과 = 전처리(캔버스);
  if (!전처리결과) { 상태글.textContent = "그림이 비어 있습니다"; return; }
  마지막결과 = 추론_단계별(가중치, 전처리결과.입력);
  마지막전처리 = 전처리결과;
  단계_그리기();
}
```
