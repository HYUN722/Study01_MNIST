# 손글씨 인식기 웹/데스크톱 분리 스펙

<!-- 작성일: 2026-09-27 04:35 (KST) -->

## 목표

하나의 MNIST CNN 모델을 **데스크톱 앱**과 **웹 앱** 두 형태로 제공한다.
학습은 데스크톱에서만 하고, 웹은 그 결과를 받아 추론만 한다.

## 사용자 요구사항 (수현님 원문 기준)

1. 손글씨 인식 프로그램을 **웹 버전과 데스크톱 버전으로 나누어** 개발한다.
2. 웹 버전은 **외부 라이브러리 없이 순수 자바스크립트로 추론**한다.
3. 웹 버전은 **GitHub Pages에 정적으로 올릴 수 있어야** 한다.
4. `web_version` 폴더는 새로 작성한다.
5. 기존 코드는 `desktop_version` 폴더로 이동한다.
6. 각 폴더에 해당하는 `CLAUDE.md` 를 만든다.

## 범위 밖

* 웹에서의 학습 (추론 전용)
* 여러 자리 숫자 인식 (한 번에 숫자 하나)
* 서버 API, 사용자 데이터 저장, 계정

## 제약

| 항목 | 값 |
|------|-----|
| 웹 의존성 | 0개. CDN·npm·번들러·프레임워크 금지 |
| 배포 형태 | 정적 파일만. 빌드 단계 없음 |
| 모델 구조 | 기존 `MnistCNN` 유지 (Conv 32 → Conv 64 → MaxPool → FC 128 → FC 10) |
| 전처리 | 데스크톱 `utils.py` 와 동일한 5단계·동일 상수 |
| 정규화 | 평균 0.1307, 표준편차 0.3081 |
| 축소·정렬 | 긴 변 20px, 무게중심 (13.5, 13.5) |
| 언어 | 코드·주석·변수명·출력 메시지 전부 한글 |
| 파일 헤더 | `작성일: YYYY-MM-DD HH:MM (KST)` |
| 개인정보 | 사용자가 그린 그림을 서버로 전송하지 않는다 |

## 성공 기준

1. 웹 추론 결과가 **동일 입력·동일 가중치에서 파이토치 결과와 1e-5 이내**로 일치한다.
2. GitHub Pages 주소에서 숫자를 그려 **정상 인식**된다.
3. 데스크톱 버전이 폴더 이동 후에도 학습·인식 모두 동작한다.
4. 두 버전의 전처리 상수가 일치하며, 문서에 그 불변 조건이 명시돼 있다.
5. 재학습 후 웹에 반영하는 절차가 한 줄 명령으로 가능하다.

## 열린 질문 (해소됨)

* **가중치 전달 형식** → 헤더 없는 float32 리틀엔디언 바이너리(`model.bin`). JSON은 파일이
  3배 이상 커지고 파싱 비용이 크며, int8 양자화는 정확도 확인 부담이 있어 1차 범위에서 제외.
* **웹 폴더 위치** → 저장소 루트의 `web_version/`. Pages 를 `main / (root)` 로 켜고
  `/Study01_MNIST/web_version/` 경로로 접근.
