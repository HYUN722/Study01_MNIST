# 손글씨 숫자 인식기 (MNIST + CNN)

손으로 쓴 숫자(0~9)를 인식하는 학습용 프로젝트입니다.
같은 CNN 모델을 **데스크톱 앱**과 **웹 앱** 두 가지로 만들었고,
모든 코드와 주석은 한글로 작성했습니다.

| | 데스크톱 버전 | 웹 버전 |
|---|---|---|
| 폴더 | `desktop_version/` | `web_version/` |
| 실행 | 윈도우 + Python | 브라우저만 있으면 됨 |
| 추론 | PyTorch | **순수 자바스크립트** (외부 라이브러리 없음) |
| 학습 | O (MNIST 6만 장) | X (가중치를 받아 씀) |
| 설치 | Python, PyTorch 필요 | 설치 없음 |

```
desktop_version/train.py  →  mnist_cnn.pt
                              ↓  웹_가중치_내보내기.py
                          web_version/model.bin  →  브라우저에서 추론
```

## 데스크톱 버전 써 보기

```powershell
cd desktop_version
py app.py
```

`app.py` 하나가 ① 필요한 패키지 설치 → ② `mnist_cnn.pt` 가 없으면 학습 →
③ 손글씨 인식 창 실행까지 알아서 진행합니다. 폴더에서 **더블클릭**해도 됩니다.

| 옵션 | 설명 |
|------|------|
| `py app.py --에폭 5` | 학습 에폭 수 지정 (기본 3) |
| `py app.py --재학습` | 가중치가 있어도 다시 학습 |
| `py app.py --학습생략` | 학습 없이 GUI 만 실행 |

바탕 화면 바로가기를 만들려면 `desktop_version/바로가기_만들기.py` 를 한 번 실행하세요.
콘솔 창 없이 인식 창만 뜨고, 작업 표시줄에 고정할 수 있습니다.

## 모델 구조

```
입력 (1, 28, 28)
 → Conv 3×3, 32채널 + ReLU        (26×26)
 → Conv 3×3, 64채널 + ReLU        (24×24)
 → MaxPool 2×2                    (12×12)
 → Dropout 25%
 → Flatten (9216)
 → Linear 9216→128 + ReLU
 → Dropout 50%
 → Linear 128→10 → LogSoftmax
```

* 손실 함수 `NLLLoss`, 최적화 `Adadelta` + `StepLR(gamma=0.7)`
* 데이터 증강: 회전 ±10°, 이동 ±10%, 확대축소 0.9~1.1배
* 3에폭 학습으로 시험 정확도 **99% 안팎**
* 매개변수 1,199,882개

## 전처리 (두 버전 공통)

학습 데이터와 입력 그림의 형태를 맞추는 것이 정확도의 핵심입니다.

1. 흑백으로 바꾸고, 배경이 밝으면 반전해 **검정 배경 + 흰 글씨**로 통일
2. 글씨가 있는 영역만 잘라내기
3. 비율을 유지하며 긴 변을 **20px** 로 축소
4. 28×28 캔버스에 넣고 **무게중심을 정중앙(13.5, 13.5)** 으로 이동
5. 평균 `0.1307`, 표준편차 `0.3081` 로 정규화

데스크톱은 `utils.py`, 웹은 `preprocess.js` 에 같은 순서로 구현돼 있습니다.
