# 손글씨 숫자 인식기 (MNIST + PyTorch CNN)

마우스로 숫자를 그리면 학습된 CNN 이 0~9 중 어떤 숫자인지 맞혀 주는 프로그램입니다.
모든 코드와 주석은 한글로 작성했습니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `app.py` | **통합 실행 파일** — 패키지 설치 → 학습 → GUI 를 한 번에 |
| `model.py` | CNN 모델 구조 정의 (합성곱 2층 + 완전연결 2층) |
| `utils.py` | 손으로 그린 그림을 MNIST 형식 28x28 로 바꾸는 전처리 |
| `train.py` | MNIST 로 학습하고 가중치를 `mnist_cnn.pt` 로 저장 |
| `draw_gui.py` | 마우스로 그려서 인식하는 GUI 창 (tkinter) |
| `predict.py` | 저장된 이미지 파일을 인식 (GUI 없이 확인용) |
| `requirements.txt` | 필요한 패키지 목록 |

## 가장 쉬운 실행 방법

명령 프롬프트에서 이 폴더로 이동한 뒤 아래 한 줄만 실행하면 됩니다.

```
cd %USERPROFILE%\OneDrive\Desktop\Study01_MNIST
python app.py
```

`app.py` 가 알아서 ① 필요한 패키지 설치 → ② `mnist_cnn.pt` 가 없으면 학습 →
③ 손글씨 인식 창 실행까지 순서대로 진행합니다.

| 옵션 | 설명 |
|------|------|
| `python app.py --에폭 5` | 학습 에폭 수 지정 (기본 3) |
| `python app.py --재학습` | 가중치가 있어도 다시 학습 |
| `python app.py --학습생략` | 학습 없이 GUI 만 실행 |

아래는 단계별로 직접 실행하고 싶을 때의 방법입니다.

## 단계별 실행 순서

### 1단계. 패키지 설치 (처음 한 번만)

명령 프롬프트에서 이 폴더로 이동한 뒤:

```
cd %USERPROFILE%\OneDrive\Desktop\Study01_MNIST
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install numpy pillow
```

> `tkinter` 는 파이썬 공식 설치본에 기본 포함되어 있어 따로 설치하지 않습니다.

### 2단계. 학습하기

```
python train.py
```

* MNIST 데이터(약 11MB)를 `./data` 폴더에 자동으로 내려받습니다.
* 기본 5 에폭을 학습하며, CPU 기준 에폭당 약 3~6분 걸립니다.
* 매 에폭 끝에 시험 정확도를 출력하고, 가장 좋은 성적일 때 `mnist_cnn.pt` 를 저장합니다.
* 최종 정확도는 보통 **99% 이상**입니다.

빠르게 확인만 하고 싶다면 에폭을 줄이세요(1 에폭도 98% 정도 나옵니다):

```
python train.py --에폭 1
```

### 3단계. 손글씨로 인식해 보기

```
python draw_gui.py
```

* 왼쪽 검은 칸에 마우스를 끌어 숫자를 그립니다.
* 마우스를 놓으면 즉시 인식되어 오른쪽에 결과·확률 막대·모델이 보는 28x28 이미지가 표시됩니다.
* `[지우기]` 버튼 또는 마우스 오른쪽 버튼으로 새로 그립니다.

이미지 파일로 확인하려면:

```
python predict.py 내그림.png --보여주기
```

## 잘 인식되게 그리는 요령

* **칸을 가득 채우도록 크게** 그립니다. 작게 그리면 확대 과정에서 선이 뭉개집니다.
* 숫자는 **한 칸에 하나만** 그립니다(여러 개를 그리면 전체를 하나로 묶어 인식합니다).
* 너무 기울이지 않고 반듯하게 쓰면 정확도가 올라갑니다.

## 전처리가 하는 일 (`utils.py`)

학습 데이터와 입력 그림의 형태를 맞춰 주는 것이 정확도의 핵심입니다.

1. 흑백으로 바꾸고, 배경이 밝으면 색을 반전해 **검정 배경 + 흰 글씨**로 통일
2. 글씨가 있는 영역만 잘라 내기
3. 가로세로 비율을 유지하며 긴 변을 **20 픽셀**로 축소
4. 28x28 검정 캔버스에 넣고 **무게중심을 정중앙**으로 이동
5. MNIST 통계(평균 0.1307, 표준편차 0.3081)로 정규화

## 모델 구조

```
입력 (1, 28, 28)
 → Conv 3x3, 32채널 + ReLU        (26x26)
 → Conv 3x3, 64채널 + ReLU        (24x24)
 → MaxPool 2x2                    (12x12)
 → Dropout 25%
 → Flatten (9216)
 → Linear 9216→128 + ReLU
 → Dropout 50%
 → Linear 128→10 → LogSoftmax
```

* 손실 함수: `NLLLoss` (LogSoftmax 와 짝)
* 최적화: `Adadelta`, 에폭마다 학습률 0.7배 감소
* 데이터 증강: 회전 ±10°, 이동 ±10%, 확대축소 0.9~1.1배
  — 마우스로 삐뚤삐뚤 그린 글씨에도 잘 대응하도록 넣었습니다.
